# Accessibility checks

## Roles and labels
- Every pressable has `accessibilityRole` (`button`, `link`, `tab`, `switch`, `checkbox`, …) and an accessible name: its text, or `accessibilityLabel` for icon-only controls. Missing name on an icon button: **P1**.
- `accessibilityLabel` describes the purpose ("Delete trip"), not the look ("Trash icon"). Use `accessibilityHint` only for non-obvious results.
- State is exposed with `accessibilityState` (`selected`, `checked`, `disabled`, `expanded`, `busy`), not only by colour.
- Decorative images: `accessible={false}` / `importantForAccessibility="no"`; meaningful images have a label.
- Headings: `accessibilityRole="header"` on screen and section titles.
- Group related text (a list row's title + subtitle) with `accessible` on the container so it's read as one item.

## Focus order and navigation
- Reading order follows the visual order (top to bottom, start to end). Absolutely positioned elements don't jump the order.
- Modals and sheets trap focus (`accessibilityViewIsModal` on iOS) and return focus when closed.
- Custom gestures (swipe to delete) have an accessible alternative (`accessibilityActions`).

## Contrast
- Text: at least **4.5:1**. Large text (≥ 18pt regular or ≥ 14pt bold) and essential icons / control borders: at least **3:1**.
- Check both light and dark mode, and text on images or gradients (add a scrim).
- Placeholder text is not the only label of an input.

## Touch targets
- At least 48×48 dp (Android) / 44×44 pt (iOS). Smaller visuals use `hitSlop` or padding. At least 8 dp between adjacent targets.
- The matrix audit (`small-touch-target`) is a hint: confirm visually, because `hitSlop` doesn't show in the dump.

## Font scaling
- OS font scaling stays enabled. Screens remain usable at 2.0× (`font-200` profile): text wraps, buttons grow, content scrolls. Cap with `maxFontSizeMultiplier` only for chrome that can't grow (tab labels, badges).

## Reduce motion
- Respect the OS reduce-motion setting (`useReducedMotion()` in Reanimated / `AccessibilityInfo.isReduceMotionEnabled()`): replace large movement with fades or no animation.
- No auto-playing motion that can't be paused; nothing flashes more than 3 times per second.
