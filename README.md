# mobile-kit

A Claude Code plugin for React Native / Expo projects: device control, a multi-size device matrix, testing, design proposals with independent evaluation, UI/UX review and motion. It also installs selected third-party skills into your project on demand.

> Status: early development (v0.1.0, not released yet).

## Install

```
/plugin marketplace add kavazvah/mobile-kit
/plugin install mobile-kit@kavazvah-mobile
/mobile-kit:init
```

`init` is not available yet. The full README follows in a later release.
